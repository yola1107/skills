# 文档规范

新增、修改或评审文档时，按任务读取对应指南。

| 用途 | 本地指南 | 来源 |
| --- | --- | --- |
| Markdown 排版 | [Markdown style guide](markdown-style.md) | [Google 固定版本](https://github.com/google/styleguide/blob/7c3eb00dd3a3308003c5c8a79c4290dc1c8a8c53/docguide/style.md) |
| 篇章组织 | [Organizing large documents](large-docs.md) | [Google 官方 Markdown 导出](https://developers.google.com/tech-writing/two/large-docs.md.txt) |
| 段落表达 | [Paragraph structure](paragraph-structure.md) | [Google 官方 Markdown 导出](https://developers.google.com/style/paragraph-structure.md.txt) |

用户要求及仓库规范优先。中文按自然句段书写，不机械按 80 列折行；仓内导航使用相对链接。

原文保持不改，其中站内链接按来源站点解析。网页指南为 2026-11-07 下载快照。
