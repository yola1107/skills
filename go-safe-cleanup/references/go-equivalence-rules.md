# Go Equivalence Rules

Check typed nil/interface conversions and method sets; error identity/wrapping/precedence/partial results; nil versus empty slices/maps; map presence versus zero; slice backing-array sharing/len/cap/append/subslice/copy; pointer/value receivers and copying synchronization-bearing values; call count/evaluation/short-circuit/branch exclusivity; defer timing/capture/LIFO/recover boundary; byte versus rune and numeric conversion behavior; time/timer/random consumption; init/blank imports/registries/reflection/generated code/build tags; and repository-declared Go version semantics.

Direct-call search and “tests pass” are evidence, not complete proof for reflection, registration, external contracts or concurrency.
