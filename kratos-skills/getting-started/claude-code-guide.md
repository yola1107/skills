# 在编码助手中使用

本技能使用通用 `SKILL.md` 结构，可放在当前助手支持的技能目录中；调用方式以宿主环境为准。Codex 中可以使用 `$kratos-skills`。无需为每个仓库安装重复副本，也不要求新增助手专用权限配置。

## 请求示例

- “使用 kratos-skills，为现有 v3 服务增加一个查询 RPC，保持现有数据库访问方式。”
- “检查 Wire cleanup 是否覆盖启动失败和正常停止。”
- “按 go.mod 中的 v3 版本核对限流与熔断配置。”
- “为既有 HTTP 协议添加手写路由，保持签名正文与响应格式。”

按[入口](../SKILL.md)定位当前任务需要的专题；已有仓库答案与未变化的核验结果直接复用。

## 更新本地修订

普通编辑保留可恢复的版本差异。覆盖安装、同步上游或没有可靠恢复来源时，在技能发现路径之外备份并校验；先比较差异，保留本地修订。

更新后检查入口、引用、正文中的 API 与行为断言，以及受影响示例；正文中的错误不会因代码块编译通过而被发现。示例行为有变化或证据不足时，按项目允许环境验证；复用仍覆盖当前内容的结果。
